# LocalCast

## Что делает LocalCast

LocalCast - это локальный web-сервис на Python для управления и трансляции мультимедийного контента внутри локальной сети.

Сервис позволяет:

- загружать видео и изображения через административную панель;
- автоматически воспроизводить контент в браузерном плеере;
- управлять воспроизведением через web-интерфейс;
- использовать систему на Smart TV, телефонах, планшетах и компьютерах.

---

# Основные возможности

- авторизация администратора;
- загрузка одного или нескольких файлов;
- удаление отдельных файлов;
- удаление всех файлов;
- отображение списка загруженного контента;
- browser-based player;
- автоматическое воспроизведение медиа;
- поддержка видео и изображений;
- повтор плейлиста;
- повтор одного файла;
- режим перемешивания;
- переключение между файлами;
- fullscreen режим;
- управление с клавиатуры;
- уведомления об успешной загрузке и удалении файлов.

# Как работает система

1. Сервер запускается на компьютере внутри локальной сети.
2. Администратор входит в web-панель.
3. Через админку загружаются видео и изображения.
4. Файлы автоматически сохраняются в папку `tv_content/common`.
5. Пользователь открывает browser player по ссылке `/player`.
6. Контент автоматически воспроизводится по очереди.

---

# Важно знать

- сервер и устройства должны находиться в одной локальной сети;
- контент управляется через административную панель;
- Smart TV открывает трансляцию через встроенный браузер;
- воспроизведение работает без VLC и сторонних приложений.

# Запуск сервера

```bash
python server.py
```

После запуска сервер будет доступен локально по адресу:

```text
http://127.0.0.1:8000
```

Для подключения с других устройств внутри локальной сети необходимо использовать IP-адрес компьютера:

```text
http://IP_КОМПЬЮТЕРА:8000
```

Проверка работы сервера:

```text
http://127.0.0.1:8000/health
```

Если всё работает, вернётся:

```json
{"status": "ok"}
```

# Авторизация администратора

Перед входом в административную панель необходимо авторизоваться.

Страница входа:

```text
http://IP_КОМПЬЮТЕРА:8000/login
```

Логин и пароль задаются в `config.py`.

Пример:

```python
ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "LocalCast_Admin_2026"
SECRET_KEY = "localcast_secret_key"
```

После авторизации создаётся session cookie.

---

# Административная панель

Админка доступна по адресу:

```text
http://IP_КОМПЬЮТЕРА:8000/admin
```

Через административную панель доступны:

1. Загрузка одного или нескольких файлов;
2. Удаление отдельных файлов;
3. Удаление всех файлов;
4. Просмотр списка контента;
5. Уведомления об успешных действиях;
6. Переход к трансляции;
7. Выход из аккаунта.

Все файлы автоматически сохраняются в:

```text
tv_content/common
```

# Browser Player

Плеер доступен по адресу:

```text
http://IP_КОМПЬЮТЕРА:8000/player
```

Пример:

```text
http://192.168.0.15:8000/player
```

---

# Управление плеером

Плеер поддерживает:

- воспроизведение и паузу;
- следующий файл;
- предыдущий файл;
- перемешивание;
- повтор плейлиста;
- повтор одного файла;
- полноэкранный режим.

# Использование на Smart TV

Для использования на Smart TV:

1. Подключить телевизор к той же сети, что и сервер;
2. Открыть встроенный браузер;
3. Перейти по адресу:

```text
http://IP_КОМПЬЮТЕРА:8000/player
```

После этого трансляция начнёт воспроизводиться автоматически.

---

# Где хранятся файлы

Все медиафайлы сохраняются в папку:

```text
tv_content/common
```

Папка создаётся автоматически при запуске сервера.

# Особенности реализации

Проект состоит из нескольких основных частей:

- `server.py` - FastAPI backend;
- `config.py` - настройки проекта;
- `media_lib.py` - работа с медиаконтентом;
- `templates/admin.html` - административная панель;
- `templates/player.html` - browser player;
- `templates/login.html` - авторизация администратора.

---

# Безопасность

В проекте реализована базовая session-based авторизация администратора.

Защищены:

- вход в админку;
- загрузка файлов;
- удаление файлов;
- удаление всех файлов.

Также реализована защита от выхода за пределы папки с медиаконтентом при запросе файлов через URL.
